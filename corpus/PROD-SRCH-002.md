# Insight Search: Query Limits

*Help Center article for TechSync Insight customers.*

## Overview

To keep searches fast for everyone, Insight sets limits on how long a search can run and how much it can return. This article explains what you can expect.

## Search time limit

**By default, a search stops after 60 seconds.** If your search is stopped, you will see a message saying it timed out, along with any partial results.

## Tips if your search times out

1. **Narrow the time range.** Searching one hour is faster than searching a week.
2. **Add filters early.** Start your query with the fields that remove the most data.
3. **Use saved searches** for expensive queries you run often.
4. **Break a large question into parts.** Run each part and compare results.

## Result limits

A search returns up to 1,000 rows in the table view. Use **Export** to download more.

## Concurrent searches

You can run several searches at once. If you run many together, some may wait briefly.

## Need more?

If you often reach these limits, contact your account team to talk about your plan.
