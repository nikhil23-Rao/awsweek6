# TechSync Mobile Supported Platforms

*Reference. Updated when the support policy changes.*

## Minimum operating system versions

| Platform | Minimum version | Notes |
|---|---|---|
| iOS | **iOS 16** | iPhone only |
| Android | Android 10 (API level 29) | Phones; tablets best effort |

The minimum iOS version moved to iOS 16 in March 2026.

## What this means

- The App Store listing requires iOS 16 or later.
- Users on earlier iOS versions can keep the last compatible app version but will not receive new features or fixes.
- Support will help those users upgrade their devices or use Console in a browser.

## Device coverage

The team tests on a rotating set of devices that represents roughly 95% of active users. The device list is reviewed each quarter.

## Tablets and wearables

Tablets can install the apps but layouts are not optimized. There is no watch app.

## Changing the minimum version

The Mobile Tech Lead proposes a change when usage data shows the older version has fallen below 3% of active users. Changes are announced in release notes at least one release ahead.
