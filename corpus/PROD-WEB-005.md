# Console Ownership and Escalation Contacts

**Maintained by:** Apps Eng Engineering Manager

## Who owns what

Console, the shared web console, is owned by the Apps Eng organization. Day-to-day engineering sits with the Console squad. Design system work is handled by the same squad.

## Escalation paths

| Problem | Contact |
|---|---|
| Console UI or behavior | Console squad, #apps-eng-console |
| Build or deploy infrastructure | Core Eng, #core-eng-help |
| Cluster or networking problems | Core Eng on-call, #core-eng-oncall |
| Anything urgent after hours | Page the Console squad on-call |

## Platform issues

For problems that appear to come from the platform rather than from Console itself, escalate to Core Eng. Include the time the problem started, the affected environment, and any error messages.

## Meetings

- Console squad standup: weekdays at 10:00 Pacific.
- Apps Eng leadership sync: Mondays.

## Updating this page

If contacts change, email the Apps Eng Engineering Manager. Please do not edit the table directly.
