# DSEC Tooling Landing Page

Start here to find documentation for the systems DSEC teams own. Each entry gives a one-line description, the owning team, and the documents to read first.

## Data Platform (DATA)

**Reservoir** is the data lake.
- Read first: Table Layout and Partitioning Runbook, Batch Ingestion Job Runbook, Dataset Onboarding FAQ

**Streamline** is the Kafka event bus.
- Read first: Topic Naming Conventions, Schema Registry Guide, Consumer Lag Troubleshooting

## ML Infrastructure (MLI)

**Foundry** is the platform for ML training and serving.
- Read first: Operator Onboarding Guide, Training Job Submission Runbook, Model Serving Rollout Guide

**FeatureHub** is the feature store.
- Read first: Ingestion and Offline Store Guide, Feature Definition Standard

## AppSec (SEC)

**Sentinel** scans code and dependencies.
- Read first: Dependency Scanning Standard, False Positive Triage FAQ, Rule Tuning Guide

**Vaultline** manages secrets.
- Read first: Secrets Engine Setup Guide, Dynamic Secrets Runbook

## IT & Compliance (ITC)

- Read first: SSO Configuration Guide, Application Onboarding Checklist, Role and Group Naming Standard

**Compass** tracks compliance evidence.
- Read first: the Compliance Evidence Handbook
